A tiny program that writes one short family scene to a text file. The scene
is a single line of at most 280 characters: Grandma's Wi-Fi password is
still the year grandad was born, and she tells every visitor, "He's gone,
but he still lets people in."

## Run it

```sh
python3 main.py
```

It writes the scene to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory). Running it twice produces byte-identical output. The program uses
only the Python standard library and needs no network access.
